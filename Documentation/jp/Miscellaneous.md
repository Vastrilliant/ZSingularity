# MISCELLANEOUS
## Custom Greeting Text

自分のプレイヤーカードに表示される挨拶文を上書きします。

**注: クライアント側にのみ適用されます。**

## Hide user ID

UID が動画やスクリーンショットに表示されないよう、画面上で隠します。

**注: クライアント側のみの変更であり、ProjectMoon のサーバーから UID を隠すことはできません。**

## Disable Liquid Glass

tweak の liquid glass を無効にし、blur ベースの UI デザインへ置き換えます。

反映するにはアプリの再起動が必要です。
