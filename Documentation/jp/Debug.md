# DEBUG

Debug セクションは、プロセス自身の `stdout`/`stderr` をリアルタイムで表示するビューアです。すべての `NSLog` 呼び出しが書き込むものと同じストリームであり、tweak 自身のログは `ZLog` マクロを通じてこのストリームに書き込まれます。ビューア自身がログ行を生成することはなく、すでに存在するログをキャプチャして表示します。

この回避策は、iOS18+ で NSLogs を直接読み取った際のログ破損を防ぐために必要です。

## Syslog

プロセスの `stdout` と `stderr` のファイルディスクリプタをパイプへリダイレクトし、どちらかに書き込まれた各行を発生時に読み取ることでキャプチャします。元のディスクリプタは保持され、読み取った各行は直後に元へ書き戻されます。そのため、ビューアを開いていることによってプロセス本来のログ動作が変わることはありません。デバイスコンソールやデバッガなど、`stdout`/`stderr` を読む他のツールからも従来どおり同じ出力が見えます。

## Debug mode

**Syslog** を約1秒間長押しすると **Debug** モードに切り替わります。ログビューは、この tweak 自身のログタグを含む行だけに絞られます。ゲーム自身のログや、プロセスの `stdout`/`stderr` を共有するその他すべての出力がフィルタリングされ、この tweak が生成したメッセージだけが表示されます。

## Blacklisted keywords

**Blacklist keywords** フィールドでは、ノイズの多い特定の行を単にスクロールして通り過ぎるのではなく、完全に非表示にできます。カンマ区切りで1つ以上の語句を入力し、return を押して追加します。各語句は、すべてのログ行に対して大文字と小文字を区別しない部分文字列として照合されます。

ブラックリストの語句は:

- 今後一致する行がバッファへ入るのを防ぎます。

- すでにバッファに入っている一致行も、追加された時点ですぐに削除します。新しい出力だけを対象とするものではありません。

- 削除されるまで、tweak の他の設定と同様に再起動後も保持されます。
