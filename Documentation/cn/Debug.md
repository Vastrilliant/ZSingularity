# DEBUG

Debug 部分是进程自身 `stdout`/`stderr` 的实时查看器，也就是所有 `NSLog` 调用写入的同一输出流，其中包括 tweak 自身通过 `ZLog` 宏写入的日志。它不会自己生成日志行，而是捕获并显示已经存在的日志。

该变通方案用于避免在 iOS18+ 上直接读取 NSLogs 时造成日志损坏。

## Syslog

捕获机制会将进程的 `stdout` 和 `stderr` 文件描述符重定向到管道，因此可以在每一行写入时立即读取。原始描述符会被保留，并且每行读取后都会立即写回，因此仅仅打开查看器不会改变进程正常的日志行为。其他读取 `stdout`/`stderr` 的工具（例如设备控制台和调试器）仍然会看到与以前相同的输出。

## Debug mode

长按 **Syslog** 约一秒会切换到 **Debug** 模式。日志视图会缩小到只显示包含此 tweak 自身日志标签的行，从而过滤游戏自身的日志以及其他共享进程 `stdout`/`stderr` 的输出，只显示此 tweak 产生的消息。

## Blacklisted keywords

**Blacklist keywords** 字段可以完全静默特定的噪声日志，而不只是让它们滚动过去。输入一个或多个以逗号分隔的词语并按 return 添加；每个词语都会针对每一行日志进行不区分大小写的子字符串匹配。

加入黑名单的词语会:

- 阻止今后匹配的日志行进入缓冲区。
- 在添加后立即删除已经缓冲且匹配的日志行，而不仅仅过滤之后的新输出。
- 与 tweak 的其他设置一样持续保存，直到被移除。
