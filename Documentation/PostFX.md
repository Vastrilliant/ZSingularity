# POST FX
## Bloom

Internally known as 'HDR', this is the game's bloom setting.

## Motion Blur

**Not to be confused with 'Blur'.**
This is an internal, unused post-processing effect, separate from the game's regular blur.

Its values range from 0 to 1.00. It enables a motion blur effect whenever the camera moves, with the effect's strength increasing at higher values.

## Tonemap

Internal Unity Engine setting.

Tone mapping is a technique used in image processing and computer graphics to map one set of colors to another, approximating the appearance of high-dynamic-range (HDR) images in a medium with a more limited dynamic range.

## Chromatic Aberration & Lens Distortion

Post-processing effects used by certain skills and screen effects.

## Vignette & Film Grain

Ambient effects applied throughout the game that are normally not user-editable.

## Saturation & White Balance

Internal Unity Engine setting; set to 0 by default.
