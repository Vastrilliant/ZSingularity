# DISPLAY
## Normal FPS

Управляет ограничением частоты кадров игры в сценах меню / UI.

## Combat FPS

Управляет ограничением частоты кадров игры в боевых сценах.

Боевые сцены значительно более требовательны к рендерингу, чем меню, поэтому для них используется отдельное ограничение от Normal FPS.
