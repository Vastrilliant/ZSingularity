# MISCELLANEOUS
## Custom Greeting Text

Заменяет приветственную фразу, отображаемую на вашей собственной карточке игрока.

**ПРИМЕЧАНИЕ: действует только на стороне клиента.**

## Hide user ID

Визуально скрывает ваш UID, чтобы он не отображался на видео или скриншотах.

**ПРИМЕЧАНИЕ: действует только на стороне клиента и не скрывает ваш UID от серверов ProjectMoon.**

## Disable Liquid Glass

Отключает liquid glass в tweak и заменяет его UI-дизайном на основе blur.

Для применения требуется перезапуск приложения.
