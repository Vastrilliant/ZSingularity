# PARTICLES
## Alignment

Определяет ориентацию particle effects относительно камеры и мира:

- 0 = View
- 1 = World
- 2 = Local
- 3 = Facing
- 4 = Default

`4 = Default` восстанавливает alignment в исходное состояние.

## Render Mode

Определяет способ рендеринга частиц.

ПРИМЕЧАНИЕ: каждая particle system обычно имеет собственный режим рендеринга. Эта настройка принудительно применяет выбранный режим ко всем particle system в игре, переопределяя исходные значения.

- 0 = Billboard
- 1 = Stretched Billboard
- 2 = Horizontal Billboard
- 3 = Vertical Billboard
- 4 = Mesh
- 5 = None
- 6 = Default

`5 = None` отключает каждый particle effect.

`6 = Default` восстанавливает каждый particle effect в исходное состояние.

## Sort Mode

Определяет порядок сортировки и отрисовки частиц относительно друг друга:

- 0 = None
- 1 = Distance
- 2 = Oldest Front
- 3 = Youngest Front

## Min Size & Max Size

Определяет минимальный и максимальный размер, при котором particle effects могут отображаться, как долю высоты экрана (0–1).

ПРИМЕЧАНИЕ: увеличение Min Size выше исходного размера частицы может привести к непредвиденным последствиям.

## Freeform Stretching

Определяет, разрешено ли частицам свободно растягиваться независимо от направления их движения.

**ПРИМЕЧАНИЕ: визуальный эффект появляется только у particle system, использующих Stretched Billboard render mode.**

## Max Count Cap

Определяет максимальное количество частиц, одновременно существующих в одной сцене. При включении любая particle system, количество частиц которой превышает установленный предел, будет ограничена этим пределом.
