# УПРАВЛЕНИЕ ПАМЯТЬЮ
## Entitlements

У iOS-приложения могут быть два entitlement, позволяющих использовать больше памяти.

`com.apple.developer.kernel.increased-memory-limit` позволяет приложению запросить у iOS больше памяти. **Этот entitlement не действует на iPhone с объёмом памяти менее 4GB.**

`com.apple.developer.kernel.extended-virtual-addressing` включает 64-битное виртуальное адресное пространство, позволяя приложению отображать значительно более крупные области адресов.

Хотя сам по себе этот entitlement **не** увеличивает физическую память, он критически важен для приложений, которым нужно одновременно отображать несколько огромных блоков данных. Расширяя границы виртуальных адресов, он предотвращает сбои выделения памяти из-за фрагментации адресного пространства.

Этот entitlement доступен только для платных аккаунтов разработчика Apple.

## Extend Memory Usage

Используя app extensions, ZS может переносить управляемые кучи IL2CPP и области памяти malloc в app extension, у которого отдельный лимит памяти.

Это позволяет приложению фактически обходить ограничения памяти Apple, и iPhone всего с 3GB памяти могут в основном нормально запускать игру.

Учтите, что для этого требуется зарегистрировать дополнительный App ID.

## Redirect minimum

Фильтрует, какие области управляемой памяти IL2CPP переносятся. Более низкие пороги переносят больше памяти, но могут снизить стабильность.

## Memory Cleanup

Освобождает память, которую игра больше не использует, выгружая неактивные кэшированные объекты.

К ним относятся:
* неактивные экземпляры из пулов
* кэшированные assets
* неиспользуемые render target камер
* портреты в бою
* VFX-эффекты боя
* резервные материалы текста и другие внутренние кэши

Затем дважды запускается `GC.Collect()`.

При запуске возможен кратковременный скачок лагов.
