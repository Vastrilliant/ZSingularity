# MISCELLANEOUS
## Custom Greeting Text

자신의 플레이어 카드에 표시되는 인사 문구를 덮어씁니다.

**참고: 클라이언트 측에서만 적용됩니다.**

## Hide user ID

UID가 동영상이나 스크린샷에 나타나지 않도록 화면에서 숨깁니다.

**참고: 클라이언트 측에서만 적용되며 ProjectMoon의 서버에서 UID를 숨기지는 않습니다.**

## Disable Liquid Glass

tweak의 liquid glass를 비활성화하고 blur 기반 UI 디자인으로 교체합니다.

적용하려면 앱을 재시작해야 합니다.
